# KRMA TX

App de escritorio de **KRMA Esports** para transmitir torneos con OBS:

- monta las escenas de KRMA TX en OBS con un clic y las sirve desde tu PC;
- controla la transmisión desde la misma ventana (las escenas de OBS y el panel);
- lee el oro de Mobile Legends y Wild Rift desde la imagen de OBS;
- trae los datos en vivo de CS2 sin instalar nada más.

## Descargar

La última versión está en **[Releases](https://github.com/KRMA-Esports/krma-tx/releases/latest)** (Windows 10 u 11, 64 bits).
Necesitas OBS 28 o más reciente y un plan de KRMA TX: **[krmaesports.com/tx](https://krmaesports.com/tx/)**.

La app se actualiza sola (nunca con OBS en directo). Este repositorio solo guarda las versiones para descargar.
